# IR Sketch Has Moved

IR Sketch has been replaced by [Imprint Sketch](/utilities-imprint-sketch.html).
The new utility includes the complete room workflow and adds caves, caverns,
passages, open fields, abstract spaces, deterministic generation, and mutation.

Existing IR Sketch project JSON remains supported. The former browser URL and
REAPER action redirect to Imprint Sketch for compatibility.
